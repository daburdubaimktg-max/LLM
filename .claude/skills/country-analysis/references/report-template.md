# Report templates — five HTML files per invoke

Deliver **self-contained** HTML (all CSS inline, no external fetches — this environment blocks many),
brand palette **`#1B5E20` (deep green) / `#2D7D32` (mid green) / `#F57C00` (accent orange)**, with
print-CSS so it exports cleanly to PDF/Office. Clone `assets/report_shell.html` per report. Save all five
to the user's selected folder, then present them.

Naming: `[COUNTRY]_MACRO_Country_Entry_Foundation.html` and
`[COUNTRY]_[Category]_Category_Analysis_and_Entry_Strategy.html`.

## Report 1 — COUNTRY_MACRO (the shared foundation)
Section order = macro heads: cover (country, entrant, four categories, date, "public data — re-validate"
banner) → M1 Demographics → M2 Economy & affordability → M3 Politics/geopolitics/trade/legal → M4 History/
religion/values/cohorts/occasions → M5 Media/digital/news/social ecosystem (with the named-outlets &
platform tables) → M6 Retail & e-commerce platform map (named platforms + doors) → M7 Health-system/
pharmacy/regulatory spine (the Two Doors) → M8 Origin-headwind & localization doctrine → M9 Language &
brand-name legality → **Own-brand portfolio audit (O1–O6 rolled up): awareness, availability, purchase,
sentiment, current positioning, and the consolidated white-space + positioning-space maps** → M11
Portfolio-sequencing synthesis + portfolio Reputation Bet → M10 Source-confidence & re-validation register
→ appendix: the local-language deep-research prompt(s).

## Reports 2–5 — Category decks (DEEP — benchmark: ~6,000–9,000 words, ≥20 tables)

Each **references the macro report** for country context (callout, don't repeat). This is a board-grade
deep-dive, not a skeleton. Every section below lists its **required artifact** — build that artifact, do
not substitute a prose sentence. Section order = C1–C18:

| # | Section | Required artifact (minimum) |
