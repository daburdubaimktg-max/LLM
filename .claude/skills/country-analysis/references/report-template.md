# Report templates — five HTML files per invoke

Deliver **self-contained** HTML (all CSS inline, no external fetches — this environment blocks many),
brand palette **`#1B5E20` (deep green) / `#2D7D32` (mid green) / `#F57C00` (accent orange)**, with
print-CSS so it exports cleanly to PDF/Office. Clone `assets/report_shell.html` per report. Save all five
to the user's selected folder, then present them.

Naming: `[COUNTRY]_MACRO_Country_Entry_Foundation.html` and
`[COUNTRY]_[Category]_Category_Analysis_and_Entry_Strategy.html`.

→ appendix: the local-language deep-research prompt(s).
