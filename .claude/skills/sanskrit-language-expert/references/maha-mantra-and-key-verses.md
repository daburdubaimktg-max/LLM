## 1. The Hare Kṛṣṇa Mahā-mantra

### Full text (IAST)

```
Hare Kṛṣṇa Hare Kṛṣṇa
Kṛṣṇa Kṛṣṇa Hare Hare
Hare Rāma Hare Rāma
Rāma Rāma Hare Hare
```

### Devanāgarī

```
हरे कृष्ण हरे कृष्ण कृष्ण कृष्ण हरे हरे ।
हरे राम हरे राम राम राम हरे हरे ॥
```

### Word-by-word phonetic breakdown

**Hare** — *Ha-re* (3 beats)
- *Ha*: guttural *h* (back of throat) + short *a* (1 beat, throat-vowel)
- *re*: cerebral *r* (tongue tip near hard palate) + long *e* (2 beats, diphthong — never short)
- **Vocative form** addressing Hari/Harā (Rādhā). Always 3 beats total.

**Kṛṣṇa** — *Kṛṣ-ṇa* (2 beats)
- *Kṛṣ*: guttural *k* (back of throat) + vocalic *ṛ* (tongue vibrates near hard palate, "ri" sound but more guttural) + retroflex *ṣ* (tongue curled back to hard palate, "sh" sound)
- *ṇa*: retroflex *ṇ* (tongue curled back to hard palate, "n" sound) + short *a* (1 beat)
- **Three retroflex movements in one word.** Tongue curls back twice (for ṣ and ṇ).
- **Final 'a' preserved.** Never "Krishn" — the ending *a* is essential.

**Rāma** — *Rā-ma* (3 beats)
- *Rā*: cerebral *r* (tongue near hard palate) + long *ā* (2 beats — held for the count of two)
- *ma*: labial *m* (lips closed) + short *a* (1 beat)
- **Held vowel.** *Rā* is twice as long as *ma*.

### Beat-by-beat reading (one full mahā-mantra round = 32 mātrās)

```
Ha-re   Kṛṣ-ṇa   Ha-re   Kṛṣ-ṇa
1+2     1+1      1+2     1+1     = 8 beats

Kṛṣ-ṇa  Kṛṣ-ṇa   Ha-re   Ha-re
1+1     1+1      1+2     1+2     = 8 beats

Ha-re   Rā-ma    Ha-re   Rā-ma
1+2     2+1      1+2     2+1     = 12 beats? Let me recount...
```

Actually the simpler way — and the way the mantra is *actually* sung — is to give each syllable equal rhythmic weight in chanting (japa) while preserving the vowel-length distinctions in articulation. The mātrā analysis above is for understanding the sounds, not for imposing a strict metronome on the chant.

### Articulation map

| Syllable | Articulation point | Movement |
|---|---|---|
| Ha | Throat (guttural h + a) | Open mouth, voice from throat |
| re | Hard palate area (r) → diphthong e | Tongue near roof, mouth shaping toward "ay" |
| Kṛ | Throat (k) → tongue vibrates near palate (ṛ) | Sharp k, tongue pulls up |
| ṣ | Hard palate (curled tongue) | "sh" with tongue curled back |
| ṇa | Hard palate (curled n) + throat-vowel a | Tongue still curled, then releases for a |
| Rā | Hard palate area (r) + throat-vowel held long | Tongue near roof, vowel sustained 2 beats |
| ma | Lips (m) + throat-vowel a | Lips close briefly, then open for a |

### Critical articulation rules for the Mahā-mantra

1. **Both Kṛṣṇa retroflexes must be made cleanly.** The *ṣ* and the *ṇ* both require curling the tongue back. If you say "Krishna" with a flat tongue, neither sound is correct.
2. **The *ṛ* in *Kṛṣṇa* is a vowel, not a consonant.** It is one of the rare vocalic-r sounds. Tongue vibrates near (does not strike) the hard palate.
3. **Final *a* is always there.** *Kṛṣṇa* ends on a soft schwa-like *a*, not on the *ṇ*.
4. **The *e* in *Hare* is a diphthong, always long.** Never shorten.
5. **The *ā* in *Rāma* is held for two beats.** Never shorten *Rāma* to *Rama* (rhyming with *llama*).
6. **No nasalization unless marked.** The *n* in *Hare* and the *m* in *Rāma* are clean — no anusvāra (ṃ) unless explicitly written.

### The five points of origin in this single mantra

The Mahā-mantra exercises **all five** points of articulation in one cycle:

- **Throat (guttural):** *Ha* (h, a), *Kṛ* (k), every *a*-vowel
- **Soft palate (palatal):** every *e* and the start of every *Ha-re*
- **Hard palate (cerebral/retroflex):** *ṛ*, *ṣ*, *ṇ*, *r* — multiple instances
- **Teeth (dental):** *na* in some traditions, and the brief approach of tongue
- **Lips (labial):** *ma* in *Rāma*

Chanting the Mahā-mantra correctly is a complete śikṣā exercise — it tones the entire articulation apparatus.

## 2. The Pañca-tattva Mahā-mantra

### Full text (IAST)

```
(jaya) śrī-kṛṣṇa-caitanya
prabhu-nityānanda
śrī-advaita gadādhara
śrīvāsādi-gaura-bhakta-vṛnda
```

### Phonetic breakdown

**śrī** — *Śrī* (2 beats)
- Palatal *ś* (soft "sh" — tongue blade against soft palate, gentler than *ṣ*) + cerebral *r* (tongue near hard palate) + long *ī* (2 beats)

**kṛṣṇa** — *Kṛṣ-ṇa* (2 beats — same as Mahā-mantra)

**caitanya** — *Cai-tan-ya* (4 beats)
- *Cai*: palatal *c* (= "ch", soft palate) + diphthong *ai* (2 beats — begins guttural, ends palatal)
- *tan*: dental *t* (tongue at teeth) + short *a* + dental *n* (halanta — no following vowel)
- *ya*: palatal *y* + short *a*

**prabhu** — *Pra-bhu* (2 beats)
- *Pra*: labial *p* (lips) + cerebral *r* + short *a*
- *bhu*: labial *b* + breath puff + short *u*

**nityānanda** — *Nit-yā-nan-da* (5 beats)
- *Nit*: dental *n* + short *i* + dental *t* (halanta)
- *yā*: palatal *y* + long *ā* (2 beats)
- *nan*: dental *n* + short *a* + dental *n* (halanta)
- *da*: dental *d* + short *a*

**advaita** — *Ad-vai-ta* (4 beats)
- *Ad*: short *a* + dental *d* (halanta)
- *vai*: labio-dental *v* + diphthong *ai* (2 beats)
- *ta*: dental *t* + short *a*

**gadādhara** — *Ga-dā-dha-ra* (5 beats)
- *Ga*: guttural *g* + short *a*
- *dā*: dental *d* + long *ā* (2 beats)
- *dha*: dental *d* + breath puff + short *a* (note the breath — *dh* not *d*)
- *ra*: cerebral *r* + short *a*

**śrīvāsādi** — *Śrī-vā-sā-di* (6 beats)
- *Śrī*: as above (2 beats)
- *vā*: labio-dental *v* + long *ā* (2 beats)
- *sā*: dental *s* (clean dental "s") + long *ā* (2 beats)
- *di*: dental *d* + short *i*

**gaura** — *Gau-ra* (3 beats)
- *Gau*: guttural *g* + diphthong *au* (2 beats — begins guttural, ends labial)
- *ra*: cerebral *r* + short *a*

**bhakta** — *Bhak-ta* (2 beats)
- *Bhak*: labial *b* + breath + short *a* + guttural *k* (halanta)
- *ta*: dental *t* + short *a*

**vṛnda** — *Vṛn-da* (2 beats)
- *Vṛn*: labio-dental *v* + vocalic *ṛ* (tongue vibrates near hard palate) + dental *n* (halanta)
- *da*: dental *d* + short *a*

### Critical points

- **Caitanya** uses palatal *c* (= "ch"), NOT *k*. The IAST *c* is always "ch" as in *church*.
- **Three different "sh"-like sounds** appear: *ś* (palatal — soft, in *śrī*) and the absence of *ṣ* (no retroflex sh in this mantra). Don't substitute one for the other.
- **Two diphthongs** to watch: *ai* in *Caitanya* and *advaita*; *au* in *gaura*. Both are always long (2 beats).

## 3. Praṇāma Mantras

### 3a. Śrī Guru Praṇāma

```
oṁ ajñāna-timirāndhasya
jñānāñjana-śalākayā
cakṣur unmīlitaṁ yena
tasmai śrī-gurave namaḥ
```

#### Key articulation points

**oṁ** — *Oṁ* (2 beats)
- Long *o* (2 beats — diphthong) + anusvāra *ṁ* (nasal vibration, lips closing toward labial)

**ajñāna** — *A-jñā-na* (4 beats)
- *A*: short *a* (independent vowel)
- *jñā*: palatal *j* + palatal *ñ* (palatal nasal) + long *ā* (2 beats)
- *na*: dental *n* + short *a*
- **The *jñ* conjunct is one of the most distinctive Sanskrit sounds.** In Bhaktivedanta tradition, *jñ* is pronounced as something close to "gy" or a soft "jn" — Prabhupāda often pronounced it closer to "gya" (so *jñāna* sounds like "gyā-na"). This is a North-Indian convention; the strict South-Indian pronunciation is "jña" with both consonants articulated. **Either is acceptable for ISKCON chanting.**

**timirāndhasya** — *Ti-mi-rān-dha-sya* (6 beats)
- *Ti*: dental *t* + short *i*
- *mi*: labial *m* + short *i*
- *rān*: cerebral *r* + long *ā* (2 beats) + dental *n* (halanta)
- *dha*: dental *d* + breath + short *a*
- *sya*: dental *s* + palatal *y* + short *a*

**cakṣur** — *Cak-ṣur* (2 beats)
- *Cak*: palatal *c* (= "ch") + short *a* + guttural *k* (halanta)
- *ṣur*: retroflex *ṣ* (tongue curled, "sh") + short *u* + cerebral *r* (halanta)

**namaḥ** — *Na-maḥ* (2 beats)
- *Na*: dental *n* + short *a*
- *maḥ*: labial *m* + short *a* + visarga *ḥ* (soft echo "ha" — *na-ma-(h)a*)

### 3b. Śrī Pañca-tattva Praṇāma

```
pañca-tattvātmakaṁ kṛṣṇaṁ
bhakta-rūpa-svarūpakam
bhaktāvatāraṁ bhaktākhyaṁ
namāmi bhakta-śaktikam
```

#### Key articulation points

**pañca-tattvātmakaṁ** — three components
- *pañ*: labial *p* + short *a* + palatal *ñ*
- *ca*: palatal *c* (= "ch") + short *a*
- *tat*: dental *t* + short *a* + dental *t* (halanta — geminate)
- *tvāt*: dental *t* + labio-dental *v* + long *ā* + dental *t*
- *ma*: labial *m* + short *a*
- *kaṁ*: guttural *k* + short *a* + anusvāra (nasal)

**bhakta** — *Bhak-ta* (see common-words-and-names.md)

**bhaktāvatāraṁ** — *Bhak-tā-va-tā-raṁ* (7 beats)
- *Bhak*: labial *b* + breath + short *a* + guttural *k*
- *tā*: dental *t* + long *ā* (2 beats)
- *va*: labio-dental *v* + short *a*
- *tā*: dental *t* + long *ā* (2 beats)
- *raṁ*: cerebral *r* + short *a* + anusvāra

### 3c. Śrī Kṛṣṇa Praṇāma

```
he kṛṣṇa karuṇā-sindho
dīna-bandho jagat-pate
gopeśa gopikā-kānta
rādhā-kānta namo 'stu te
```

#### Critical points

**he** — *He* (2 beats — long e)
- Guttural *h* + long *e* (2 beats — diphthong)

**karuṇā** — *Ka-ru-ṇā* (4 beats)
- *Ka*: guttural *k* + short *a*
- *ru*: cerebral *r* + short *u*
- *ṇā*: retroflex *ṇ* (curled tongue) + long *ā* (2 beats)

**namo 'stu te** — *Na-mo ʼs-tu te* (5 beats)
- *Na*: dental *n* + short *a*
- *mo*: labial *m* + long *o* (2 beats)
- *ʼs*: avagraha (elided *a*) + dental *s* — read as *mo* held longer, then *stu*
- *tu*: dental *t* + short *u*
- *te*: dental *t* + long *e* (2 beats)
- **Avagraha note:** This is *namo astu te* with *aḥ + a → o + ʼa* sandhi. The apostrophe marks where *a* of *astu* was elided. Read it with a brief pause or vowel extension after *namo*.

### 3d. Śrīla Prabhupāda Praṇāma

```
nama oṁ viṣṇu-pādāya
kṛṣṇa-preṣṭhāya bhū-tale
śrīmate bhaktivedānta-
svāminn iti nāmine
```

#### Key articulation points

**viṣṇu** — *Viṣ-ṇu* (2 beats)
- *Viṣ*: labio-dental *v* + short *i* + retroflex *ṣ* (curled tongue)
- *ṇu*: retroflex *ṇ* (curled tongue) + short *u*
- **Two retroflex movements.** Tongue curled back for both *ṣ* and *ṇ*.

**preṣṭhāya** — *Pre-ṣṭhā-ya* (5 beats)
- *Pre*: labial *p* + cerebral *r* + long *e* (2 beats)
- *ṣṭhā*: retroflex *ṣ* (curled tongue) + retroflex *ṭ* + breath puff + long *ā* (2 beats)
- *ya*: palatal *y* + short *a*
- **Three retroflex events:** ṣ, ṭ, and the breath that aspirates ṭ. Most demanding articulation in a praṇāma.

**bhū-tale** — *Bhū-ta-le* (5 beats)
- *Bhū*: labial *b* + breath + long *ū* (2 beats)
- *ta*: dental *t* + short *a*
- *le*: dental *l* + long *e* (2 beats)

**svāminn iti** — note the double *n* (gemination) and the conjunct flow

## 4. Maṅgalācaraṇa — A common opening invocation

### vande 'haṁ verse (frequently used as a maṅgalācaraṇa)

```
vande 'haṁ śrī-guroḥ śrī-yuta-pada-kamalaṁ śrī-gurūn vaiṣṇavāṁś ca
śrī-rūpaṁ sāgrajātaṁ saha-gaṇa-raghunāthānvitaṁ taṁ sa-jīvam
sādvaitaṁ sāvadhūtaṁ parijana-sahitaṁ kṛṣṇa-caitanya-devaṁ
śrī-rādhā-kṛṣṇa-pādān saha-gaṇa-lalitā-śrī-viśākhānvitāṁś ca
```

#### Key articulation challenges

**vande 'haṁ** — *van-de ʼ-haṁ* (5 beats)
- *van*: labio-dental *v* + short *a* + dental *n*
- *de*: dental *d* + long *e* (2 beats)
- *ʼ*: avagraha — pause or extend *de*
- *haṁ*: guttural *h* + short *a* + anusvāra

**śrī-guroḥ** — *Śrī gu-roḥ* (5 beats)
- *Śrī*: 2 beats (palatal ś + cerebral r + long ī)
- *gu*: guttural *g* + short *u*
- *roḥ*: cerebral *r* + long *o* (2 beats) + visarga (echo "ha" colored by *o* → "ho")

**vaiṣṇavāṁś ca** — *Vai-ṣṇa-vāṁś ca* (5 beats)
- *Vai*: labio-dental *v* + diphthong *ai* (2 beats)
- *ṣṇa*: retroflex *ṣ* + retroflex *ṇ* + short *a* (two retroflex movements!)
- *vāṁś*: labio-dental *v* + long *ā* + anusvāra + palatal *ś*
- *ca*: palatal *c* (= "ch") + short *a*

This single phrase exercises both retroflex *ṣ* and *ṇ*, both palatal *ś* and *c*, and a diphthong *ai*. Excellent training material.

## 5. The Eight Verses of Śikṣāṣṭakam

Lord Caitanya's only written verses. They are foundational. Full IAST below — phonetic breakdowns of selected difficult lines follow.

### Verse 1
```
ceto-darpaṇa-mārjanaṁ bhava-mahā-dāvāgni-nirvāpaṇaṁ
śreyaḥ-kairava-candrikā-vitaraṇaṁ vidyā-vadhū-jīvanam
ānandāmbudhi-vardhanaṁ prati-padaṁ pūrṇāmṛtāsvādanaṁ
sarvātma-snapanaṁ paraṁ vijayate śrī-kṛṣṇa-saṅkīrtanam
```

**Sound to watch:** *saṅkīrtanam* ends with a guttural nasal *ṅ* before *k* — back of tongue at velum. Same articulation point as *k*.

### Verse 2
```
nāmnām akāri bahudhā nija-sarva-śaktis
tatrārpitā niyamitaḥ smaraṇe na kālaḥ
etādṛśī tava kṛpā bhagavan mamāpi
durdaivam īdṛśam ihājani nānurāgaḥ
```

**Sound to watch:** *etādṛśī* contains vocalic *ṛ* and palatal *ś*. *Ta-vā kṛ-pā* — tongue vibrates for *kṛ*, then long *ā*.

### Verse 3 (the famous "tṛṇād api sunīcena" verse)
```
tṛṇād api sunīcena
taror api sahiṣṇunā
amāninā mānadena
kīrtanīyaḥ sadā hariḥ
```

#### Phonetic breakdown of the most-quoted verse in Vaiṣṇavism

**tṛṇād** — *Tṛ-ṇād* (3 beats)
- *Tṛ*: dental *t* + vocalic *ṛ* (tongue vibrates near hard palate)
- *ṇād*: retroflex *ṇ* (curled tongue) + long *ā* (2 beats) + dental *d* (halanta)

**api** — *A-pi* (2 beats) — short *a* + labial *p* + short *i*

**sunīcena** — *Su-nī-ce-na* (5 beats)
- *Su*: dental *s* + short *u*
- *nī*: dental *n* + long *ī* (2 beats)
- *ce*: palatal *c* (= "ch") + long *e* (2 beats)
- *na*: dental *n* + short *a*

**sahiṣṇunā** — *Sa-hi-ṣṇu-nā* (5 beats)
- *Sa*: dental *s* + short *a*
- *hi*: guttural *h* + short *i*
- *ṣṇu*: retroflex *ṣ* + retroflex *ṇ* + short *u* (two retroflex)
- *nā*: dental *n* + long *ā* (2 beats)

**kīrtanīyaḥ** — *Kīr-ta-nī-yaḥ* (6 beats)
- *Kīr*: guttural *k* + long *ī* (2 beats) + cerebral *r* (halanta)
- *ta*: dental *t* + short *a*
- *nī*: dental *n* + long *ī* (2 beats)
- *yaḥ*: palatal *y* + short *a* + visarga (soft echo)

**sadā hariḥ** — *Sa-dā ha-riḥ* (5 beats)
- *Sa*: dental *s* + short *a*
- *dā*: dental *d* + long *ā* (2 beats)
- *ha*: guttural *h* + short *a*
- *riḥ*: cerebral *r* + short *i* + visarga (echo "hi" colored by *i*)

## Quick reference — articulation challenges by verse type

| Verse type | Most challenging features |
|---|---|
| Mahā-mantra | Three retroflex sounds in *Kṛṣṇa* (ṛ, ṣ, ṇ); long *ā* in *Rāma* |
| Pañca-tattva | The *jñ* conjunct in *jñāna*-related words; multiple long vowels |
| Praṇāma to Prabhupāda | The *ṣṭhā* conjunct in *preṣṭhāya* — three retroflex events |
| Śikṣāṣṭakam verse 3 | *tṛṇād* (vocalic ṛ + retroflex ṇ); *sahiṣṇunā* (double retroflex) |
| Long invocations | Sustained breath for compound words; visarga echoes at line ends |
