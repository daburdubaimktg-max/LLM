# Reports

One folder per country: `reports/<batch>-<country-slug>/` (e.g. `reports/B9-uae/`).

Five HTML files per country, produced in this order, **one full-depth pass each**:

1. `<COUNTRY>_MACRO_Country_Entry_Foundation.html`
2. `<COUNTRY>_HairCare_Category_Analysis_and_Entry_Strategy.html`
3. `<COUNTRY>_OralCare_Category_Analysis_and_Entry_Strategy.html`
4. `<COUNTRY>_OTC_HealthCare_Category_Analysis_and_Entry_Strategy.html`
5. `<COUNTRY>_SkinCare_Category_Analysis_and_Entry_Strategy.html`

Quality bar: `benchmarks/vietnam/` — ~6,000–9,000 words, ≥20 tables, all 8 mandatory modules,
closing Reputation Bet. Rejection checklist: `kit/0_START_HERE_HANDOVER.md` §7.

When a batch completes, add `reports/<batch>-SUMMARY.md` ranking its countries by
attractiveness × right-to-win.
