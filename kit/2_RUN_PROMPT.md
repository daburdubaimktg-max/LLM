## C. Nudges to keep quality up (use as needed mid-run)

- If a report comes back thin:
  `Too thin. Rebuild this category at full reference depth: >=6,000 words, >=20 tables, all 8 mandatory modules, real local-language ad copy + LEAP table, >=25-term glossary. Expand every section that is currently one-liners into an evidence-carrying table.`

- If it starts compressing all four categories:
  `Stop - one category per pass at full depth. Do Hair only, in full, now. We'll do the next category in a fresh pass.`

- If it invents numbers or omits sources:
  `Every hard number needs a source + date. Mark anything you can't source as "Source gap" and add it to the re-validation queue - do not fabricate.`

- If it defaults to China-style conclusions:
  `Re-derive from [COUNTRY]'s own data: entry lane, origin stance, demand engine, price bands. Do not transplant China. Show the local evidence for each.`

- To force the local-language research prompt when sources are gated:
  `The decisive sources here are [language]-language and login-walled. Don't fake depth - emit a ready-to-paste [language] deep-research prompt I can run in a native engine / hand to an in-country colleague.`

## D. Order of countries (suggested, if you have a list)

Do the highest-priority / most decision-relevant country first while everyone is fresh, and the ones with a matching regional expert (China, MENA, India, Sub-Saharan Africa) before the gap-rule ones - the expert-backed runs are richer and set the quality bar for the rest.
